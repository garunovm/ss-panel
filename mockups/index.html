Макеты панели ИХС

Каркас — как Task CRM FD (боковое меню, шапка, карточки), цвета — ИХС. Раздел видно по цвету: admin.* — янтарный, doctor.* — синий. Решения — в ../plans/.

admin.* — главная

  • Главнаяна согласовании«что сделать сегодня» по роли (учебная часть / менеджер / админ — демо-переключатель): задачи, запуски в работе, ближайшие даты, новое за сутки, цифры года

admin.* — Институт (главное: курсанты, документы, удостоверения, ФИС ФРДО)

  • Курсантына согласованиивсе курсанты одним списком: все / новые / прошли курсы, запуск, курс, год, специальность, город, быстрые фильтры; карточка — справа: личные данные, документы, курсы, история событий
  • Запуск курсовна согласованиизапуски в работе и завершённые; запуск уходит в «Завершённые» после подтверждения ФИС ФРДО (предложение)
  • Запуск: мастер-курс 27–28.11на согласовании«Курсанты» — проверка документов из кабинета (принять / вернуть с причиной); «Документы» — начало документооборота
  • Запуск: продвинутый 23–24.10на согласовании«Курсанты» — посещение и аттестация; «Документы» — документооборот по порядку (шаблоны Word, ЭЦП) и ФИС ФРДО: проверка полей, файл, «отправлено», «принято»

admin.* — специалисты

  • Специалисты: списокна согласованиироли, публикация ИХС / FD / RF, учётная запись, правки, «правит коллега»
  • Карточка специалистана согласованиивкладки: данные (отметки полей), публикация, учётная запись, слоты, курсы, журнал; демо «коллега открыл карточку» (WebSocket)
  • Схема карточкина согласованииадмин добавляет свойства: тип, «врач правит», «через подтверждение», «на сайты»
  • На подтверждениена согласовании«было → стало», принять / вернуть с причиной; новая клиника с проверкой на дубль

admin.* — обучение и система

  • Курсы и запускина согласованиикурсы по направлениям, услуга 1С, запуски по годам, публикация
  • Курсна согласованиизапуски (даты, место, статус, места, цена, программа), «запуск копией прошлого», о курсе
  • Программа запускана согласованииинтерактивная: дата начала + регламент → время считается само; перетаскивание пунктов и менторов, ↑ ↓, свой регламент у пункта, правка на месте, «конец дня» с предупреждением; демо «коллега правит день 2». Образец и для панели RF
  • Клиники и местана согласованииединый справочник экосистемы: приём врачей и/или курсы, помещения для программы, правка на месте, предложенные из кабинета врача
  • Списки значенийна согласованиинаправления, специальности, степени (общие экосистемы), роли, типы пунктов, документы, статусы запуска; порядок перетаскиванием, архив вместо удаления
  • Пользователи и ролина согласованииучётки заводит админ; роль → раздел; врач ↔ карточка, ассистент ↔ врачи; вход; матрица прав по ролям
  • Журнална согласованиитолько дописывается: изменения («было → стало»), обмен с сайтами, входы и отказы в доступе (403); фильтры, выгрузка CSV
  • Сайты и ключи APIв очередимакет «api.*»: ключи сайтов, права, журнал запросов, что видит API

# Макеты панели ИХС

Статичный HTML, открывать `index.html` в браузере. Данные — примеры; программа курса — по реальной
программе продвинутого курса 23–24 октября 2026 (`content\Курсы\2026\`).

- **Каркас** — как Task CRM FD (TailAdmin: боковое меню, шапка, карточки), **цвета** — ИХС
  (палитра из `../../../repo/mockups/css/tokens.css`). Раздел видно по цвету: `<body data-app="admin">` —
  янтарный акцент, `data-app="doctor"` — синий.
- `css/panel.css` — всё оформление; в Laravel станет `@utility`-классами, как в `app.css` Task CRM.
- `js/panel.js` — меню и шапка по `<body data-app data-page>`, вкладки, фильтр таблиц, боковая форма,
  очередь на подтверждение, демо присутствия (WebSocket), всплывающие сообщения.
- `img/` — фото специалистов и логотип из макетов сайта; `fonts/` — Ubuntu Condensed для заголовков.
- Доступность — как на сайте (WCAG 2.2 AA): контраст ролей, фокус, подписи полей, клавиатура во вкладках.

# Встречи — протоколы

Правило — facts.md 2026-11-23 «Правило встреч» (для всех проектов), образец — FD (`footdoctor/repo/meetings/`).

- Встречи по панели: менеджеры и руководители направлений ИХС; партнёры (FD). Панель — демо-пилот,
  решения по спорным местам — после оценки.
- Один файл на встречу: `ГГГГ-ММ-ДД-кто.md` (`2026-11-27-ихс-менеджеры.md`).
- **До встречи** протокол открывается заранее по шаблону `_шаблон.md`: Claude собирает «Вопросы» из
  `plans/next.plans.md` (открытые пункты) и пометок «предварительно — до встречи»; пользователь дописывает
  свои — до встречи и во время неё.
- **После встречи** Claude оформляет протокол и в том же коммите разносит решения по тематическим
  `plans/*.plans.md` и facts.md; у каждого решения — пометка, куда записано. Задачи — по форме (`forms.md`).
- **Протокол — история, не источник решений.** Изменилось решение — правим план, протокол не трогаем.
- Неотвеченное переходит в «Вопросы» следующей встречи.
- Без ПДн: имена и роли, без телефонов, почт и т. п.

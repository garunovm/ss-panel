# Курсанты, документы, ФИС ФРДО

Главное назначение панели (пользователь, 2026-11-19).

## Сейчас

- Документы курсанты загружают в кабинете сайта ИХС, учебная часть принимает или возвращает с
  причиной; счета, акты и оплаты остаются в 1С (facts 2026-10-23).
- **Документы курсанта для удостоверения** (уточнение пользователя, 2026-11-23):
  - **СНИЛС** — скан + номер. Номер проверяется по контрольной сумме (опечатка в одну цифру даёт ошибку сразу,
    при вводе — и в кабинете, и в панели).
  - **Диплом** — скан + данные: серия и номер, дата выдачи, учебное заведение, направление / специальность и
    другие поля, которые требует ФИС ФРДО (полный список — сверить с приказом № 831 и шаблоном загрузки).
  - **ИНН** (пользователь, 2026-11-23) — поле номера, 12 цифр, проверка по контрольным цифрам при вводе. Для
    удостоверения и ФИС ФРДО не нужен; нужен для справки об оплате обучения для налогового вычета (ИНН
    налогоплательщика — того, кто платил) и для договора с плательщиком. ⚠ Предварительно — до встречи: обязательное
    или по желанию; чей ИНН (курсанта или плательщика, если платит не он); справку делает 1С или панель.
  - Вносит **курсант в кабинете сайта ИХС** или **менеджер / учебная часть в панели** (например, принёс бумаги
    лично); правка из панели — в журнал, курсант видит её в кабинете.
- **Что выдаём** (пользователь, 2026-11-23):
  - **сертификат — всегда**, каждому, кто прошёл курс;
  - **удостоверение о повышении квалификации — только при принятых СНИЛС и дипломе** (и зачёте); в ФИС ФРДО
    уходят только удостоверения. Нет документов — курсант получает сертификат, удостоверение можно выдать позже,
    когда документы приняты (⚠ предварительно — до встречи с учебной частью: срок «позже» и нужен ли новый приказ).

- **Документы по порядку** (макет 2026-11-19): договор (с плательщиком, курсанты — приложением) → приказ о
  зачислении → ведомость посещения → протокол аттестации → приказ об отчислении → удостоверения → сканы в
  кабинеты → ФИС ФРДО; следующий шаг открывается после подписи предыдущего. Шаблоны Word с метками, подпись
  ЭЦП в браузере. Перечень и порядок — сверить с учебной частью и юристом (`next.plans.md`).
- **ФИС ФРДО:** панель проверяет поля у каждого курсанта, собирает файл только для готовых (не готовые ждут
  следующей выгрузки), отправляет файл сотрудник; панель хранит файл и протокол ФИС ФРДО; нумерация
  удостоверений сквозная, испорченный бланк — «аннулировано», номер не переиспользуется — вкладка
  «Документы», `mockups/pages/admin-run-adv.html` (2026-11-19).
- Личные данные курсантов видят только учебная часть и админ ([access.plans.md](access.plans.md)).

# Курсанты, документы, ФИС ФРДО

Главное назначение панели (пользователь, 2026-11-19).

## Сейчас

- Документы курсанты загружают в кабинете сайта ИХС, учебная часть принимает или возвращает с
  причиной; счета, акты и оплаты остаются в 1С (facts 2026-10-23).

  **«Институт» = «Курсанты» + подгруппа «Курсы»** («Запуск курсов», «Программа курсов»); группы «Обучение» нет
  (пользователь, 2026-11-23; «Программа курсов» — [courses.plans.md](courses.plans.md)):
  - **«Курсанты»** — один список всех (новые, прошедшие, по запуску — через фильтры); карточка курсанта
    открывается справа: личные данные (маска, просмотр — в журнал), документы, курсы, история событий —
    `mockups/pages/admin-students-all.html`;
  - **«Курсы → Запуск курсов»** — все курсы по датам, в работе и завершённые; у запуска этапы «Курсанты», «Документы» (весь
    документооборот по порядку, последний шаг — ФИС ФРДО) и «Фото и материалы»
    ([courses.plans.md](courses.plans.md)) — `mockups/pages/admin-runs.html`, `admin-run-*.html`.
  - **Завершённый запуск открывается для просмотра всех этапов** (курсанты, документы, ФИС ФРДО, фото); изменения
    закрыты, исправление (дубликат удостоверения) — через учебную часть с записью в журнал (2026-11-23) —
    `admin-run-done.html`.
  - Запуск уходит в «Завершённые» после подтверждения ФИС ФРДО — предложение пользователя, уточнить.
- **Документы по порядку** (макет 2026-11-19): договор (с плательщиком, курсанты — приложением) → приказ о
  зачислении → ведомость посещения → протокол аттестации → приказ об отчислении → удостоверения → сканы в
  кабинеты → ФИС ФРДО; следующий шаг открывается после подписи предыдущего. Шаблоны Word с метками, подпись
  ЭЦП в браузере. Перечень и порядок — сверить с учебной частью и юристом (`next.plans.md`).
- **ФИС ФРДО:** панель проверяет поля у каждого курсанта, собирает файл только для готовых (не готовые ждут
  следующей выгрузки), отправляет файл сотрудник; панель хранит файл и протокол ФИС ФРДО; нумерация
  удостоверений сквозная, испорченный бланк — «аннулировано», номер не переиспользуется — вкладка
  «Документы», `mockups/pages/admin-run-adv.html` (2026-11-19).
- Личные данные курсантов видят только учебная часть и админ ([access.plans.md](access.plans.md)).
